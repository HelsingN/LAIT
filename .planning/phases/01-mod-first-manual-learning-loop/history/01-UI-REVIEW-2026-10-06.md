## Top 3 Priority Fixes

1. **Live feedback card omits the D-18 body and the expected unit** — an incorrect submit shows only "Incorrect" plus the raw submitted string until Show answer — render `feedback.explanation` in `FeedbackCard` (`frontend/src/registries/renderers/GapFillRenderer.tsx`). If Try again / Show answer stay (shipped in 01-16), update `01-UI-SPEC.md` instead of pretending the card still matches the contract.
2. **Delete is an unlabeled 28px × with no confirmation** — one click on a selected row removes the unit — show the contract dialog ("Remove this unit? It will not appear in new exercises. Past attempts are kept."), name the control Delete, and give it a 44×44 hit target (`LearningUnitsStage.tsx` / `.remove`).
3. **The drag pass does not drag** — chips are toggle buttons and the blank is a static accent underline — either make chips draggable onto the blank and apply the accent outline only while a drag is active, or amend the contract to click-to-select.

## Detailed Findings

### Pillar 1: Copywriting (2/4)

**WARNING.** Contract strings that match, unchanged: empty lesson heading/body (`LessonListPage.tsx` 34–36), `Untitled Lesson` (8–9), `Loading…` (22), list/workspace load error (27, `LessonWorkspacePage.tsx` 47), `Creating…` / `Create Lesson` (`CreateLessonForm.tsx` 59–63), overlap error, empty-units copy, frozen hint (`LearningUnitsStage.tsx` 13–15), generate failure pair and `Generating…` (`GenerateExercisesStage.tsx` 4–7, 41), `Checking…` / `Submit Answer` / `Continue` (`GapFillRenderer.tsx` 117–123), Start Over confirmation and Exit Practice (`FocusPracticeMode.tsx` 8–9, 66–70), feedback empty state (`FeedbackStage.tsx` 88).

**WARNING.** In-session feedback does not use the D-18 templates. `FeedbackCard` prints a bare category word, the submitted string only for incorrect/corrected, and the expected unit only after reveal. It never renders `feedback.explanation`.

```172:190:frontend/src/registries/renderers/GapFillRenderer.tsx
function FeedbackCard({ feedback, revealed }: { ... }) {
  // ...
  return (
    <article className={styles.card} data-testid="feedback-card">
      <p className={tone}>{resultWord(feedback.category)}</p>
      {showSubmitted ? <p>{feedback.submitted}</p> : null}
      {revealed ? <p>{feedback.expected}</p> : null}
    </article>
  );
}
```

Contract body is `Correct. The expected answer is "{unit}".` and `Your answer: "{submitted}". Expected: "{unit}".` The card also introduces `Corrected` (`resultWord`, lines 166–167). UI-SPEC allows only `correct` | `incorrect`. 01-16 shipped Try again, Show answer, and `corrected` on purpose; the design contract was not updated. Spec drift, not a reason to delete that flow in this review.

**WARNING.** Stage toggle label is `Exercises` (`LessonWorkspacePage.tsx` 582). UI considerations lock the stage name as `Generate Exercises`. The button inside the panel still says `Generate Exercises`.

**WARNING.** Destructive confirmation copy is absent. The control’s accessible name is `Remove ${unit.text}` and the visible glyph is `×` (`LearningUnitsStage.tsx` 156–164). The contract label is `Delete`, with the confirmation sentence in the copywriting table. Checker sign-off kept the single word Delete.

**WARNING.** Extra copy not in the contract: `Exercises are ready.` (`GenerateExercisesStage.tsx` 44), `Type the missing words.` (`GapFillRenderer.tsx` 76), `Current pass` / `Earlier passes` / `Choice` / `Typed` (`FeedbackStage.tsx` 23–28, 101–108).

**Not filed (locked).** History rows still render `attempt.explanation`, which repeats the expected phrase (`FeedbackStage.tsx` 137). Deferred UX debt from 01-16. Answer field `autoComplete="off"` and `readOnly` until focus (`GapFillRenderer.tsx` 82–94) matches the locked behavior. No missed-phrases button (locked removal). Score uses `pass_item_count` as the denominator (`FeedbackStage.tsx` 49–60), which is the locked opening-pass size.

### Pillar 2: Visuals (2/4)

**WARNING.** The active-stage marker does not survive layout. `.stageOpen` draws a 4px accent bar (`LessonWorkspacePage.module.css` 165–168), then `.actions .stageOpen` sets `border-left: 0` (154–157). Source and Learning Units use `.pane` and never receive `.stageOpen` (`LessonWorkspacePage.tsx` 669–677). The contract focal point is the expanded stage; in the workspace every stage looks equally secondary.

**WARNING.** Unit rows do not show a draft or accepted badge. Tests assert those words are absent. Status is implied only by whether Accept is rendered (`LearningUnitsStage.tsx` 145–154). Contract: each row shows unit text, a draft or accepted badge, Accept when draft, Delete, and the excerpt jump. Delete appears only after the row is selected.

**WARNING.** Gap Fill blank is an empty `<span>` (`GapFillRenderer.tsx` 52). There is no drop-target outline state. Selected chips use `aria-pressed` and a static outline (`.chip[aria-pressed="true"]`). Focus Practice sentence is Source Serif 4 at body size, which does meet the focus-mode focal-point rule.

**WARNING.** After an incorrect grade, Try again, Show answer, and Continue all use `.primary` (`GapFillRenderer.tsx` 107–119). Three filled accent buttons, so Continue is not the single primary action.

**WARNING.** Start Over confirmation is an `alertdialog` with one button, also labeled Start Over, and no dismiss control (`FocusPracticeMode.tsx` 73–87). The dialog does not trap focus, so Exit Practice remains reachable, but the confirmation cannot be declined.

### Pillar 3: Color (3/4)

Tokens match the contract exactly: dominant `#F7F6F2`, secondary `#E4E9EF`, accent `#0F6E56`, destructive `#B42318` (`frontend/src/styles/tokens.css` 26–29). Page background is dominant. Stage panes and the chip well are secondary. Focus ring is accent (`:focus-visible`). Correct card text is accent; incorrect card text and the overlap/submit errors are destructive. No purple gradient, no dark theme, no Google Fonts request (`frontend/index.html` has no font stylesheet).

**WARNING.** Accent is used outside the reserved set:

- Lesson row `Open` link is `color: var(--color-accent)` (`LessonListPage.module.css` 111–115). Reserved CTAs do not include Open.
- Blank underline is always `border-bottom: 2px solid var(--color-accent)` (`GapFillRenderer.module.css` 20–25). Contract: accent outline on the blank only while dragging. This is a decorative border.
- Selected unit row outline is accent (`LearningUnitsStage.module.css` 85–87). Not in the reserved list.
- Try again and Show answer are filled accent (see Visuals). Accept’s accent border/text is allowed (Accept is a reserved CTA).

**WARNING.** History category labels use `.category` with no accent/destructive color (`FeedbackStage.module.css` 25–29, `FeedbackStage.tsx` 135–136). Contract: correct feedback text uses Accent; incorrect uses Destructive. Only the live card does this.

**WARNING.** One hardcoded duplicate of dominant: `.primary { color: #f7f6f2 }` in `LessonListPage.module.css` 76. Elsewhere primary label color uses `var(--color-dominant)`.

Text color `#1C1B19` is an extra token, not a contract color. It is body text, not an accent substitute.

### Pillar 4: Typography (3/4)

Declared scale is what ships: body 16/400/1.5 on `:root`, label 14/600/1.4 on pending and field captions, heading 20/600/1.2 on `h2` and `.stageToggle`, display 28/600/1.2 on `h1` (`tokens.css` 40–67, 175–186 in the workspace CSS). Weights in component CSS are 400 and 600 only. Source and the Gap Fill sentence use `--font-source` (Source Serif 4). Chrome uses `--font-ui` (Source Sans 3). WOFF2 files are local: `frontend/src/fonts/source-sans-3-400.woff2`, `source-sans-3-600.woff2`, `source-serif-4-400.woff2`. Fallback stacks are Segoe UI / Palatino (`tokens.css` 38–39).

**WARNING.** The Answer label and the typed instruction are 16px with inherited weight 400 (`.answerLabel`, `.instruction` in `GapFillRenderer.module.css` 65–70). The Label role is 14/600. Empty-units `h3` is restyled to heading 20/600 (`LearningUnitsStage.module.css` 15–19), so that one is fine.

### Pillar 5: Spacing (5/4 was not awarded)

**WARNING.** Declared scale is 4, 8, 16, 24, 32, 48, 64. Lesson List follows it: page padding `--space-3xl` / `--space-lg`, form gap `--space-md`, row padding `--space-lg` (`LessonListPage.module.css`). The workspace does not:

| Location | Value | Contract |
|----------|-------|----------|
| `.workspace` padding | `12px 16px 8px` | 12px is off the scale |
| `.stageColumn` gap, `.preparation` gap | `8px`, `12px` | stage breaks are `--space-2xl` (48px); 12px is off-scale |
| `.pane` padding | `12px` | stage panel padding is `--space-lg` (24px) |
| `.actions .stagePanel` padding | `0 0 8px` | overrides `.stagePanel`’s `--space-lg` |
| Unit `.row` padding | `4px 4px 4px 8px` | list row padding is `--space-lg`; unit text is not clamped to two lines |
| `.remove` | `28px × 28px` | icon-only hit target is 44×44 |

Chip `min-height: 44px` and primary buttons `min-height: 44px` meet the touch exception. Chip bank `max-height: 40vh` matches the Focus Practice overflow rule. Focus shell margin is `--space-xl` (32px), which matches Focus Mode outer margin.

**WARNING.** `.frozen` is `white-space: nowrap` plus ellipsis (`LearningUnitsStage.module.css` 39–44). The full frozen sentence will clip inside the 320px units column at `min-width: 960px`.

**WARNING.** Unit phrase text wraps with `overflow-wrap: anywhere` and no two-line clamp (`LearningUnitsStage.module.css` 89–99). Contract: wrap to two lines, then ellipsis.

### Pillar 6: Experience Design (2/4)

Present and aligned:

- List pending in the header, not a full-page blocker; empty state; create pending disables the CTA and keeps pasted text on error (`CreateLessonForm.tsx`).
- Workspace load error links back to `/`.
- Add with an empty selection is a no-op; tooltip uses the empty-selection hint (`LearningUnitsStage.tsx` 102–121).
- Overlap error copy sits under the control; controls disable while practice is open.
- Generate button shows `Generating…` and stays available on failure (`showGenerate` is true when not ready).
- Start Practice stays disabled until `practiceReady`.
- Submit disables and reads `Checking…`; transport error is `Could not submit. Try again.` and the draft input is not cleared on that path.
- Feedback stage empty copy matches; one history list, not a stack of live cards.
- Focus mode replaces the stage column (`LessonWorkspacePage.tsx` 486–516). Expansion is stored per lesson id (`stageState.ts` via `saveStageExpansion`).
- Learner types come from the registry query. Lesson feature source does not call `module_registry.describe` or hard-code the Gap Fill module id (covered by `LessonWorkspacePage.test.tsx`). Proof renderer is a separate component and is not mounted by `FocusPracticeMode` unless the learner-visible type list includes it.

**WARNING.** Drag mode is click-to-select. `ChipButton` submits on click via `onSelect`; there is no `draggable`, `onDragStart`, or `onDrop` (`GapFillRenderer.tsx` 130–156). Grading still sends `submittedUnitId`, so the identity check can succeed, but the contracted gesture and drop-target outline are missing.

**WARNING.** Delete has no confirmation step (`deleteUnit` runs on click, lines 75–87). Start Over has the contract sentence but no way to cancel the dialog.

**WARNING.** Live card does not show used/missed. The missed-phrases button removal is locked and is not a new defect. The card still omits the explanation and withholds `expected` until Show answer, so the populated-feedback rule (submitted, expected, D-18 explanation) is unmet during the session. History shows explanation plus excerpt jump after exit.

**WARNING.** Focus Practice renders the frozen-units hint (`FocusPracticeMode.tsx` 49) even though unit editing is already unmounted. Contract chrome for that mode is the renderer, the feedback region, and session navigation.

**WARNING.** No React error boundary around the workspace or the renderer registry. A thrown renderer takes down the route. Loading and request errors are handled; render crashes are not.
