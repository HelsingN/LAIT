### Restore identity and disclosure

`LessonWorkspacePage.tsx:183–204` filters by session/mode/span, chooses latest, checks a position-keyed attempt marker, and restores only incorrect feedback. It currently destroys saved fields:

```tsx

chunks_missed: [],
natural_alternative: null,
```

Replace with actual list fields. Do not equate session+unit+mode/span with a repeat-copy position: the list does not expose the original item position or learning-unit id. Use an exact attempt-id lookup from the existing position marker plus current-item consistency checks, and explicitly define fallback behavior when that marker is missing/stale. Do not select another copy's latest result. Assess correct/corrected restoration as well: submit can advance the backend cursor, so never attach the prior result to the new current item.

Bind disclosure to the selected attempt id as well, reset stale in-memory reveal state, and define legacy/unmatched reveal values as undisclosed unless safely associated.
