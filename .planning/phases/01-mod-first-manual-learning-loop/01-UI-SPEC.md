## Screens & Interaction Contract

Locked learner chrome from `01-CONTEXT.md` (D-01–D-19, D-21). Executor must implement these; do not redesign.

### Routes

| Route | Purpose |
|-------|---------|
| `/` | Lesson List entry only |
| `/lessons/:id` | Lesson Workspace (primary) |
| Focus Practice Mode | Same lesson route with session-mode chrome swap (no separate maintainer route) |

No login, no language picker, no maintainer page.

### Lesson List (entry)

- Single column list of active lessons: title + open affordance.
- Primary action creates a new lesson (paste flow).
- Opening a row navigates to `/lessons/:id`.

### Lesson Workspace (primary)

- Stages in order: **Source** → **Learning Units** → **Generate Exercises** → **Practice** → **Feedback**.
- Completing a stage unlocks and auto-expands the next. Every unlocked stage can expand/collapse independently.
- Persist expand/collapse per lesson in `localStorage` keyed by immutable lesson id (research A4).
- Title: editable before create; suggested from first meaningful source line/heading; fallback `Untitled Lesson`. Immutable internal id never shown as the primary label.
- Full source lives in a collapsible panel. Units, exercises, and feedback show a source excerpt with one-click jump that expands the source panel and scrolls/highlights that span.

### Source stage

- Paste English plain text into a multiline field; create stores immutable source.
- After create, source is read-only in Phase 1 (no edit/rename/archive UI).

### Learning Units stage

- Create only by selecting a span in the source, then pressing **Add Learning Unit**. Selection alone does nothing. Add with no selection is a no-op (no toast required; optional brief disabled-hint on the button when selection is empty).
- Stored text = exact selected span = occurrence. Unit text is not editable.
- Add → draft. **Accept** → eligible for generation. **Delete** allowed for draft and accepted before practice.
- Overlapping spans: reject; keep existing unit; show error copy below. Touching edges allowed. Same phrase in two places = two units.
- While Focus Practice Mode is open, unit add/accept/delete controls are disabled (set frozen).

### Generate Exercises stage

- Action: **Generate Exercises** from accepted units only.
- Show recoverable terminal status (`completed` / `failed`) after the command returns. Empty accepted set → failed, no items.
- Learner exercise types come only from `exercise_registry.list_visible_for("learner")`. UI must not hard-code Gap Fill module id and must not call `module_registry.describe()`.

### Practice + Focus Practice Mode

- **Start Practice** enters distraction-free Focus Practice Mode: exercise renderer, feedback region, and session navigation only. Lesson stages and unit editing are hidden.
- One item at a time. Gap Fill: sentence with only the current unit blanked; neighboring units remain visible text.
- Two passes: drag chips (all accepted units as chips; grade by `learning_unit_id`), then typed. One accepted unit → skip drag pass.
- Item order: source span position, then `learning_unit_id`.
- Typed match: trim + case-insensitive only.
- Categories shown: `correct` | `incorrect` only. Feedback body uses D-18 templates; natural alternative omitted when null.
- **Exit Practice** → `practice.finish`: restore workspace, unfreeze units.
- **Start Over** → abandon in-progress non-attempt state + `practice.start` again on the same frozen accepted set (do not return to unit editing; do not delete Attempts).

### Feedback stage (workspace)

- After leaving practice, Feedback stage lists recent attempt outcomes for the lesson (category + explanation + excerpt jump). Attempts are never deleted by Start Over.

### Out of learner UI

- Proof exercise renderer: registry + Vitest only; never in `list_visible_for("learner")`.
- No AI unit generation, no other exercise types, no retry/reveal/resume chrome.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, chip internal padding, highlight inset |
| sm | 8px | Compact control gaps, stage header padding |
| md | 16px | Default element spacing, form field padding |
| lg | 24px | Stage panel padding, list row padding |
| xl | 32px | Layout column gaps, Focus Mode outer margin |
| 2xl | 48px | Major section breaks between stages |
| 3xl | 64px | Page-level top/bottom padding on Lesson List |

Exceptions: 44×44px minimum hit target for icon-only or chip drag handles on touch (may use 44px height with `md` horizontal padding).

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 600 | 1.4 |
| Heading | 20px | 600 | 1.2 |

Weights used: **400** and **600** only. Lesson source and Gap Fill sentence use Source Serif 4 at Body size; all chrome (nav, buttons, labels, feedback chrome) uses Source Sans 3.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#F7F6F2` | Page background, Lesson Workspace canvas |
| Secondary (30%) | `#E4E9EF` | Stage panels, Lesson List rows, source panel, chip bank well |
| Accent (10%) | `#0F6E56` | Primary CTAs, focus ring, active stage indicator, source-span highlight, selected chip drop target |
| Destructive | `#B42318` | Delete unit, destructive confirmation |

Accent reserved for: primary CTAs (**Create Lesson**, **Add Learning Unit**, **Accept**, **Generate Exercises**, **Start Practice**, **Submit Answer**, **Continue**), keyboard focus ring, active/unlocked stage marker, source occurrence highlight after jump, Gap Fill blank drop-target outline when dragging.

Do not use accent for secondary buttons, body links that are not CTAs, or decorative borders. Correct feedback text uses Accent; incorrect feedback text uses Destructive. No dark-mode theme in Phase 1. No purple gradient chrome.

## UI Considerations

> Shape-rooted UI state coverage for Phase 1 learner surfaces. Empty/error COPY references `## Copywriting Contract` rows.

Applicable state considerations resolved: 22 covered, 2 backstop, 0 unresolved

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | Lesson List | ✅ covered | Renders Copywriting empty state heading/body plus Create Lesson CTA |
| empty | Learning Units list | ✅ covered | Renders empty units heading/body; Add disabled until source selection exists |
| empty | Generate Exercises result | ✅ covered | No items until successful generate; failed empty-accepted uses generate-failed copy |
| empty | Feedback stage pre-practice | ✅ covered | Stage remains locked until practice has produced at least one Attempt; after unlock with zero attempts show "No attempts yet. Start Practice to begin." |
| loading | Lesson List / Lesson get | ✅ covered | Inline label "Loading…" in list/workspace header; no full-page blocker |
| loading | Generate Exercises | ✅ covered | Button busy state + "Generating…" until terminal status returns (synchronous command) |
| loading | Practice submit | ✅ covered | Submit Answer disabled with "Checking…" until feedback payload returns |
| error | Lesson List / Lesson get | ✅ covered | Load error copy + link back to `/` |
| error | Overlap on Add | ✅ covered | Inline overlap error; existing unit unchanged |
| error | Generate failed | ✅ covered | Status region shows generate-failed copy; Generate remains available |
| error | Practice submit transport | ✅ covered | Inline "Could not submit. Try again." without leaving Focus Mode; answer field retains input |
| populated | Lesson List | ✅ covered | Rows show title; typical 1–20 lessons scroll in the list column |
| populated | Learning Units | ✅ covered | Each row: unit text, draft\|accepted badge, Accept (if draft), Delete, excerpt jump |
| populated | Gap Fill item | ✅ covered | Sentence with blank, chip bank or text input, Submit Answer |
| partial | Draft + accepted mix | ✅ covered | List shows both; Generate uses accepted only; draft rows stay visible until Accept/Delete |
| partial | Feedback fields | ✅ covered | Show answer, reference, explanation, used/missed chunk; omit natural alternative when null |
| overflow | Lesson List titles | ✅ covered | Title truncates to one line with ellipsis; full title in `title` attribute |
| overflow | Source panel | ✅ covered | Panel body scrolls vertically inside stage; page does not freeze |
| overflow | Chip bank | ✅ covered | Chips wrap within bank well; bank scrolls if taller than 40vh |
| zero-one-many | Lesson List | ✅ covered | Zero → empty state; one → single row; many → stacked rows |
| zero-one-many | Accepted units / Gap Fill passes | ✅ covered | Zero accepted → generate fails; one → typed pass only; many → drag then typed |
| long-text | Lesson title | 🧪 backstop | Display truncates; create form input wraps to 2 lines max then scrolls |
| long-text | Source / Gap Fill sentence | 🧪 backstop | Source and sentence reflow wrap; blank stays inline; no horizontal page scroll at 320px width |
| long-text | Unit row text | ✅ covered | Unit text wraps to two lines then ellipsis; full text on excerpt jump highlight |
