## Phase Goal

**Goal:** A learner can launch the local application and complete a source-to-feedback Gap Fill workflow, while maintainers can observe that it runs through documented public contracts.

The roadmap goal is not in user-story form. This gap plan covers only the failed verification truth:

**As a** learner, **I want to** get back into the open Gap Fill session after a refresh or a second Start Practice, **so that** I can complete the current item instead of staying frozen on an open row the workspace can no longer finish.

<objective>
Close the EXER-02 deadlock: practice.start returns the open session for the same accepted-set snapshot, the open row is unique per lesson, and the workspace restores that session into Focus Practice (D-05, D-10, D-23).

Purpose: A lost React session id currently makes every later start raise StaleGenerationError, so the learner cannot finish and unit edits stay frozen.
Output: Idempotent same-generation start, revision 20261002_0004, per-lesson session id, in-flight Start Practice disable.
</objective>

## Artifacts this phase produces

- `insert_open_practice_session(practice, created_at) -> PracticeSession` on `SqlAlchemyPracticeRepository` and `RepositoryBundle`. One transaction selects `status = open` for the lesson, returns that row when present, otherwise inserts the new session and its pass items and commits. `sqlalchemy.exc.IntegrityError` rolls back and re-selects the winning open row.
- Partial unique index `uq_practice_sessions_one_open_per_lesson` on `practice_sessions(lesson_id)` WHERE `status = 'open'`. Alembic revision `20261002_0004`, `down_revision = 20261001_0003`. Downgrade drops only that index. Keep non-unique `ix_practice_sessions_lesson_id`.
- `practice.start` returns `view_for` of the existing open session when `sorted(generation.accepted_unit_ids)` for that session's `generation_id` equals the current accepted id tuple. Mismatch raises `StaleGenerationError` and does not insert, close, or unfreeze.
- localStorage key `lait.practice-session.${lessonId}` via `loadOpenPracticeSessionId`, `saveOpenPracticeSessionId`, and `clearOpenPracticeSessionId` in `stageState.ts`. `isPracticeOpen(pendingStoredSession, sessionOpen)` in the same file: true while the stored id's load getPractice has not settled, otherwise `sessionOpen`. `focused` is not a parameter.
- `PracticeStage` prop `pending`. The button is disabled when `enabled` is false or `pending` is true.
